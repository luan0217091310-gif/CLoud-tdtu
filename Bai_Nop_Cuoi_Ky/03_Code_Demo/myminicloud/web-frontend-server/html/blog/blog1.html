Mạng và cổng trong Docker Compose

Nhóm MyMiniCloud · 15.11.2026

Theo dấu một yêu cầu từ cổng 80 của máy chủ vào hai máy web trong cloud-net.

Cổng máy chủ và cổng container

Cấu hình 8080:80 trên frontend nối cổng 8080 của máy chủ với cổng 80 bên trong container. Máy khác trong cloud-net gọi web-frontend-server:80 bằng tên dịch vụ Docker. Hai địa chỉ phục vụ hai phạm vi truy cập khác nhau.

Hai node web sau gateway

Nginx ở cổng 80 dùng nhóm web_cluster gồm web-frontend-server và web-frontend-server2. Hai node dùng cùng nội dung. Header X-Load-Balancer-Node và nhãn Instance xác định node phục vụ từng yêu cầu.

docker compose ps
for i in 1 2 3 4; do
  curl -sI http://localhost/ | grep -i x-load-balancer-node
done

Khi cả hai node sẵn sàng, nhóm yêu cầu tuần tự cho thấy hai tên luân phiên. File docker-compose.yml khai báo dải mạng và địa chỉ mà BIND trả lời cho các tên *.cloud.local.
