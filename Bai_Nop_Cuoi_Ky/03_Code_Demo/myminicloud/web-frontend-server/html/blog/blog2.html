API, cơ sở dữ liệu và xác thực

Nhóm MyMiniCloud · 15.11.2026

Cách Flask ghép JSON tĩnh, dữ liệu MariaDB và access token do Keycloak phát hành.

Hai nguồn dữ liệu của Flask

/api/student đọc năm bản ghi mẫu từ students.json. /api/students-db đọc bảng studentdb.students trong MariaDB. Các yêu cầu ghi dùng câu lệnh SQL có tham số và kiểm tra trường bắt buộc.

Access token cho API bảo vệ

Keycloak quản lý realm_demo0000, hai tài khoản demo và client flask-app. Flask kiểm tra chữ ký RS256 từ JWKS nội bộ, hạn dùng, issuer, audience và client trong token trước khi phục vụ /api/secure.

curl http://localhost/api/student
curl http://localhost/api/students-db
curl -i http://localhost/api/secure

Lệnh thứ ba gửi yêu cầu không có token. Mã mong đợi là 401. Chạy test_all.py để kiểm tra cả token hợp lệ lấy qua Keycloak trực tiếp và qua gateway.
